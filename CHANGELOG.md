# Change Log

All notable changes to the "codecontext-toolkit" extension will be documented in this file.

This project follows [Keep a Changelog](https://keepachangelog.com/) recommendations.

## [Unreleased]

## [0.2.1] - 2026-10-07

### Added

- Added extension icon and Marketplace metadata.
- Added repository information for better Marketplace integration.

### Changed

- Renamed the extension identifier from `code-context` to `codecontext-toolkit`.
- Updated display name to `CodeContext Toolkit`.

## [0.2.0] - 2026-10-07

### Added

- Added Generate Context from Paths workflow.
- Added Next.js route reporting.
- Added Nuxt route reporting, including Nuxt 4 `app/pages` support.
- Added Route Report Preview.
- Added grouped Explorer context menus.

### Improved

- Improved Git Diff and Before/After Git Context workflows.
- Improved multi-root workspace support.
- Improved validation and deterministic output across export and import workflows.

## [0.1.0] - 2026-09-XX

### Added

- Added project content export.
- Added project tree export.
- Added path export.
- Added content, tree, and path import workflows.
- Added editable export documents.
- Added Git Diff context export.
- Added Before/After Git Context export.
- Added Explorer context menu support.
- Added filesystem and import validation.
- Added deterministic output and automated tests.
